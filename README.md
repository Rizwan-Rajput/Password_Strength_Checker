# Password Strength Checker

## How it works
The user simply enters a password. The program checks for:
- Uppercase letter
- Lowercase letter
- Number
- Special character
- Length of 8 or more characters

## How to run
- Download Password_Strength_Checker.py
- Open your IDE and run Password_Strength_Checker.py

## Strength Levels
| Score | Strength |
|-------|----------|
| 5 | Very Strong |
| 4 | Strong |
| 3 | Moderate |
| 2 | Weak |
| 1 | Very Weak |
